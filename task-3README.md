# Random Password Generator

## Project

Oasis Infobyte - Python Programming Task 3 (Beginner Level)
## Description
A Python program that generates a random password based on the user's selected character types.
## Features
- Takes password length from the user (minimum 8).
- Supports uppercase, lowercase, numbers and symbols.
- Requires at least two character types.
- Handles invalid input.
- Allows the user to generate another password.
## How to Run
python password_generator.py
## Modules Used
- random
- string
